🔐 PDF Lock & Unlock

PDF को password से lock करें या सही password देकर unlocked copy बनाएं।

📄 PDF चुनें

कोई PDF select नहीं की गई।

⚙️ Action

Lock करने के लिए नया password कम से कम 4 characters का रखें।

⚠️ Unlock/Lock of an existing PDF is performed locally by rendering pages and rebuilding the PDF. इससे text/vector layers, forms, links और कुछ metadata preserve नहीं हो सकते। Visual content preserve करने के लिए इसे document copy की तरह इस्तेमाल करें।

आपकी PDF server पर upload नहीं होती; processing browser में होती है।
