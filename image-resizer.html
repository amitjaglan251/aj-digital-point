Image Compress

कई online forms में photo या document की maximum file-size limit होती है। ऐसी स्थिति में image को compress करना पड़ सकता है।

  • 📦 पहले required maximum file size देखें।
  • 🖼️ Image dimensions जरूरत के अनुसार कम करें।
  • 📉 JPG quality कम करने से file size कम हो सकता है।
  • ⚠️ बहुत ज्यादा compression से photo quality खराब हो सकती है।
⚠️ किसी form में यदि exact KB/MB limit दी गई है, तो उसी application की official instructions को प्राथमिकता दें।

JPG / PNG Image Information

  • 🖼️ JPG/JPEG — सामान्य photographs के लिए commonly used format है।
  • 🖼️ PNG — transparency और graphics के लिए उपयोगी format है।
  • 📦 File format वही रखें जो संबंधित application स्वीकार करता हो।
  • ⚠️ केवल extension बदलने से actual image format जरूरी नहीं बदलता।
✅ Upload करने से पहले संबंधित website की accepted file formats जरूर check करें।

Photo Guidelines

  • 📸 Recent और clear photograph रखें।
  • 💡 अच्छी lighting में photo लें।
  • 👤 Face साफ और clearly visible होना चाहिए।
  • 🧾 Background की requirement संबंधित application के अनुसार रखें।
