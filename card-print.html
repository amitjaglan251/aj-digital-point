🪪 All Card Print

Aadhaar, PAN, Voter ID, Ayushman, e-Shram, DL, RC और अन्य card की आपके पास मौजूद PDF/image को print-ready बनाएं।

🔐 Privacy: यह tool file को server पर upload नहीं करता। File आपके browser/device में ही process होती है। केवल अपने/अधिकृत दस्तावेज़ ही print करें। किसी सरकारी portal से card निकालने या access-control bypass करने की सुविधा यहाँ नहीं है।

🪪 Card Type

Card type केवल preview label/print layout के लिए है; यह किसी government record को verify या retrieve नहीं करता।

कोई file select नहीं की गई।
📐 Full Content / No Crop: PDF के हर page को 85.6 × 54 mm card में proportionally fit किया जाएगा। Page का कोई text/image crop या delete नहीं होगा; अलग aspect-ratio होने पर खाली margin रहेगा।
🔄 Manual Duplex Guide: Front + Back image लगाकर Print करें। पहले सभी Front pages print करें; फिर उसी paper stack को printer के feed direction के अनुसार वापस लगाकर Back pages print करें। Printer model के अनुसार flip/turn direction अलग हो सकती है—पहले 1 copy test करें।
