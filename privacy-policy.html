Privacy Policy

AJ DIGITAL POINT is an independent digital assistance portal. Information submitted for an assistance request is used only for request processing and status management.

Information

Name, mobile, email, update type and limited request details may be collected. Full Aadhaar number is not stored by the request form; only a masked value may be stored.

Documents

The current web form records document selection information only. File contents are not uploaded by the form.

Security

OTP, fingerprint, iris and other biometric information must not be entered on this website.

Third-party service

Firebase is used for authentication and request data storage. Access is controlled by Firebase security rules.

Official UIDAI

This is not the official UIDAI website. Final Aadhaar processing is subject to official UIDAI procedures.
